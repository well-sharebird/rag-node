## 1. 产品概述

### 1.1 产品定位

企业级 Agent 平台，提供智能体的全生命周期管理能力，包括创建、配置、运行、监控和治理。

### 1.2 核心价值主张

| 优势 | 描述 |
|------|------|
| **7×24 小时云端运行** | Agent 在云端沙箱运行，支持长程任务、在线客服、自动触发任务，具备自动休眠和毫秒级恢复能力 |
| **Harness 内核构建** | 内置编排、记忆、行动、管控四层能力，提供更快执行、更精准推理、更可靠的任务引导 |
| **全流程生命周期治理** | 统一身份、独立运行环境、全链路 Trace、效果评测与持续优化 |
| **一体化 Runtime 交付** | 完备沙箱环境、数据持久化、跨节点恢复、秒级 Fork、端口转发与预热池 |

## 2. 核心概念

### 2.1 三层架构

```
┌─────────────────────────────────────────────────────────────┐
│                      Agent Platform                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                    Runtime                            │   │
│  │  ┌────────────────────────────────────────────────┐  │   │
│  │  │                 Session 1                       │  │   │
│  │  ├────────────────────────────────────────────────┤  │   │
│  │  │                 Session 2                       │  │   │
│  │  ├────────────────────────────────────────────────┤  │   │
│  │  │                 Session N                       │  │   │
│  │  └────────────────────────────────────────────────┘  │   │
│  │                                                       │   │
│  │  +------------------+                                │   │
│  │  │   Agent Config   │ (Manifest - JSON)             │   │
│  │  +------------------+                                │   │
│  │                                                       │   │
│  │  +------------------+                                │   │
│  │  │  Sandbox (Linux) │ (文件系统 + 终端)              │   │   │
│  │  +------------------+                                │   │
│  └──────────────────────────────────────────────────────┘   │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Agent（智能体）

**定义**：一个 AI 助手的完整配置，定义了智能体的身份、能力和行为边界。

**配置要素**：

| 要素 | 说明 | 示例 |
|------|------|------|
| **模型配置** | 使用的 LLM 模型 | qwen3.5-397b, gpt-4 |
| **系统提示词** | 角色定义和行为准则 | "你是客服助手..." |
| **技能/工具** | 可调用的能力集合 | 知识库检索、API 调用、代码执行 |
| **工作空间** | 可访问的资源范围 | 知识库 ID 列表、API 白名单 |
| **运行参数** | 温度、最大 Token 等 | temperature=0.7, max_tokens=4096 |

### 2.3 Runtime（运行时）

**定义**：Agent 的独立运行环境，是 Session 背后的云端沙箱实例。

**核心特性**：
- ✅ 独立的 Linux 沙箱环境（完整文件系统 + 终端）
- ✅ Agent 配置清单（Manifest，JSON 格式）
- ✅ 支持一个或多个 Session
- ✅ 数据持久化能力
- ✅ 跨节点恢复能力
- ✅ 秒级 Copy-on-Write Fork
- ✅ 端口转发能力
- ✅ 预热池支持

**生命周期**：
```
创建 → 初始化 → 运行 → (休眠) → 唤醒 → 运行 → 销毁
```

### 2.4 Session（会话）

**定义**：用户与 Agent 之间的完整对话过程。

**核心特性**：
- ✅ 独立的对话历史
- ✅ 独立的 Agent 上下文
- ✅ 一个 Runtime 可拥有多个 Session
- ✅ 支持会话归档和恢复

**关系**：
```
Runtime (1) ────── (N) Session
  │
  ├─ Session 1: 用户 A 的咨询对话
  ├─ Session 2: 用户 B 的咨询对话
  └─ Session N: ...
```

## 3. 功能需求

### 3.1 Agent 管理

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| AG-01 | Agent 创建 | 通过声明式 JSON 配置创建新 Agent | P0 |
| AG-02 | Agent 编辑 | 修改 Agent 配置（模型、提示词、技能等） | P0 |
| AG-03 | Agent 删除 | 删除 Agent 及其关联资源 | P0 |
| AG-04 | Agent 列表 | 查看和管理所有 Agent | P0 |
| AG-05 | Agent 详情 | 查看 Agent 完整配置和运行状态 | P0 |
| AG-06 | Agent 复制 | 基于现有 Agent 快速创建新 Agent | P1 |
| AG-07 | Agent 发布 | 将 Agent 发布到公共广场 | P1 |
| AG-08 | 版本管理 | Agent 配置版本控制和回滚 | P2 |

| RT-05 | 毫秒级恢复 | 从休眠状态快速恢复运行 | P1 |
| RT-06 | 数据持久化 | 确保 Runtime 数据不丢失 | P0 |
| RT-07 | 跨节点恢复 | 节点故障时自动迁移恢复 | P1 |

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| Runtime 启动时间 | < 5 秒 | 冷启动时间 |
| Runtime 恢复时间 | < 1 秒 | 从休眠恢复 |
| 会话响应延迟 | P95 < 3 秒 | 端到端响应时间 |
| 并发 Session | > 1000/Runtime | 单 Runtime 并发能力 |
| 集群规模 | > 10000 节点 | 平滑扩展能力 |

### 4.2 可用性要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 服务可用性 | 99.9% | 月度 SLA |
| 数据持久性 | 99.999% | 数据不丢失 |
| 跨节点恢复 | < 30 秒 | 故障自动恢复 |
| 自动休眠 | 可配置 | 默认 15 分钟空闲 |

### 4.3 安全要求

| 要求 | 说明 |
|------|------|
| 沙箱隔离 | 每个 Runtime 独立沙箱环境 |
| 网络隔离 | Runtime 间网络隔离 |
| 数据加密 | 传输和存储加密 |
| 访问控制 | 基于角色的访问控制 (RBAC) |
| 审计日志 | 全量操作审计日志 |

## 6. 接口设计

### 6.1 Agent API

```
POST   /api/v1/agents              # 创建 Agent
GET    /api/v1/agents              # 获取 Agent 列表
GET    /api/v1/agents/{id}         # 获取 Agent 详情
PUT    /api/v1/agents/{id}         # 更新 Agent
DELETE /api/v1/agents/{id}         # 删除 Agent
POST   /api/v1/agents/{id}/execute # 执行 Agent
POST   /api/v1/agents/{id}/publish # 发布 Agent
POST   /api/v1/agents/{id}/duplicate # 复制 Agent
```

### 6.2 Runtime API

```
POST   /api/v1/runtimes            # 创建 Runtime
GET    /api/v1/runtimes            # 获取 Runtime 列表
GET    /api/v1/runtimes/{id}       # 获取 Runtime 详情
POST   /api/v1/runtimes/{id}/start # 启动 Runtime
POST   /api/v1/runtimes/{id}/stop  # 停止 Runtime
POST   /api/v1/runtimes/{id}/sleep # 休眠 Runtime
POST   /api/v1/runtimes/{id}/wake  # 唤醒 Runtime
GET    /api/v1/runtimes/{id}/metrics # 获取指标
```

### 6.3 Session API

```
POST   /api/v1/sessions            # 创建 Session
GET    /api/v1/sessions            # 获取 Session 列表
GET    /api/v1/sessions/{id}       # 获取 Session 详情
POST   /api/v1/sessions/{id}/message # 发送消息
GET    /api/v1/sessions/{id}/history # 获取历史
POST   /api/v1/sessions/{id}/archive # 归档 Session
POST   /api/v1/sessions/{id}/restore # 恢复 Session
```
