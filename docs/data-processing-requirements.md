**版本**: v1.0

## 1. 概述

本文档描述 KnowRAG 系统的数据处理能力需求，涵盖从文档上传到向量入库的完整处理流程。

### 1.1 数据处理流程概览

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  文档上传   │ →  │  解析提取   │ →  │  清洗脱敏   │ →  │  分块切分   │
│  Upload     │    │   Parse     │    │   Clean     │    │   Chunk     │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                              │
                                              ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  质量验证   │ ←  │  向量嵌入   │ ←  │  元数据增强  │
│  Validate   │    │   Embed     │    │  Enrich     │
└─────────────┘    └─────────────┘    └─────────────┘
```

## 2. 已实现的数据处理能力

### 2.1 文档解析能力 (Stage 2 - Parsing)

| 能力 | 状态 | 说明 |
|------|------|------|
| PDF 解析 | ✅ 已实现 | 支持 pdfplumber 表格提取 + OCR  fallback |
| Word 解析 | ✅ 已实现 | docx 格式，保留标题层级 |
| Excel 解析 | ✅ 已实现 | xlsx 格式，表格转 Markdown |
| PPT 解析 | ✅ 已实现 | pptx 格式，幻灯片转文本 |
| 纯文本 | ✅ 已实现 | txt/md 格式基础解析 |
| HTML 解析 | ✅ 已实现 | html/htm 格式，去除标签 |
| OCR 识别 | ✅ 已实现 | 图片格式 (jpg/png/tiff/bmp) OCR |
| 跨页表格缝合 | ✅ 已实现 | 支持跨页表格拼接 |
| 布局感知 | 🟡 部分实现 | 基础布局分析，LayoutLMv3 待集成 |

**支持的格式**:
- 文档：PDF, DOCX, XLSX, PPTX, TXT, MD, HTML
- 图片：JPG, JPEG, PNG, TIFF, TIF, BMP (OCR)

### 2.2 文本清洗能力 (Stage 1.5 - Cleaning)

| 能力 | 状态 | 说明 |
|------|------|------|
| 质量评分 | ✅ 已实现 | 0-1 分评分，基于文本密度、标点、停用词 |
| SimHash 去重 | ✅ 已实现 | 64 位 SimHash，汉明距离≤3 判定为重复 |
| 语言检测 | ✅ 已实现 | langdetect + 正则 fallback，支持中/英/日/韩/阿/俄 |
| PII 检测 | ✅ 已实现 | 邮箱、手机、身份证、银行卡等 |
| 噪音过滤 | ✅ 已实现 | URL、@提及、#标签、特殊字符 |
| 编码检测 | ✅ 已实现 | chardet 库检测文件编码 |

**清洗流程**:
```
原始文本 → 噪音过滤 → PII 检测 → 语言识别 → 质量评分 → SimHash 去重 → 清洁文本
```

### 2.3 数据脱敏能力 (Stage 1.6 - Desensitization)

| 能力 | 状态 | 说明 |
|------|------|------|
| 脱敏级别 | ✅ 已实现 | 无/轻度/中度/高度/自定义 |
| 邮箱脱敏 | ✅ 已实现 | zhang**@example.com |
| 手机号脱敏 | ✅ 已实现 | 138****5678 |
| 身份证脱敏 | ✅ 已实现 | 1***************1X |
| 银行卡脱敏 | ✅ 已实现 | 6222****5678 |
| 地址脱敏 | ✅ 已实现 | 可配置 |
| 姓名脱敏 | ✅ 已实现 | 可配置 |
| 自定义替换 | ✅ 已实现 | apple→苹果，CEO→首席执行官 |
| 知识库隔离 | ✅ 已实现 | 不同 KB 可配置不同脱敏策略 |

**脱敏方法**:
- REPLACE: 字符替换 (****)
- MASK: 掩码 (138****5678)
- HASH: 哈希加密
- TRUNCATE: 截断
- KEEP_FIRST/KEEP_LAST: 保留首尾

## 5. 配置管理

### 5.1 分块策略配置

```yaml
chunking:
  default_strategy: recursive
  file_type_routes:
    pdf:
      strategy: recursive
      chunk_size: 512
      chunk_overlap: 50
    md:
      strategy: semantic
      chunk_size: 768
      chunk_overlap: 100
    code:
      strategy: recursive
      chunk_size: 256
      chunk_overlap: 32
```

### 5.2 脱敏策略配置

```yaml
desensitization:
  level: medium
  enable_email_mask: true
  enable_phone_mask: true
  enable_id_card_mask: true
  enable_bank_card_mask: true
  custom_rules:
    - from: "apple"
      to: "苹果"
    - from: "CEO"
      to: "首席执行官"
```

### 5.3 同义词配置

```yaml
synonyms:
  - standard_term: "人工智能"
    synonyms: ["AI", "机器智能", "智能"]
    category: "技术术语"
  - standard_term: "苹果"
    synonyms: ["Apple", "苹果手机", "苹果公司"]
    category: "品牌"
```

## 6. 错误处理与监控

### 6.1 错误类型

| 错误类型 | 处理方式 | 重试策略 |
|----------|----------|----------|
| 解析失败 | 标记 failed，记录错误信息 | 不重试 |
| 嵌入 API 超时 | 标记 processing，等待重试 | 3 次，指数退避 |
| Milvus 插入失败 | 标记 failed，记录错误 | 3 次 |
| 质量验证失败 | 警告，继续处理 | 不重试 |

### 6.2 监控指标

- 文档处理成功率
- 各阶段处理延迟
- 嵌入 API 调用次数/失败率
- Milvus 插入吞吐量
- 脱敏触发次数统计
